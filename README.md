# Tasklight – Responsive Task Manager

**DecodeLabs Full Stack Development Internship – Project 1 (Batch 2026)**
A mobile-first, accessible task manager built with **pure HTML, CSS and JavaScript** (no frameworks).

🔗 **Live demo:** _add your GitHub Pages / Netlify link here_

## Features
- Add, edit, complete and delete tasks
- Priority (low / medium / high) and optional due date, overdue highlighting
- Filter (All / To do / Done), search and sort
- Progress bar and live counters
- Form validation with clear error messages
- Dark / light theme (remembers choice, respects OS setting)
- Data saved in `localStorage`
- Fully responsive: 375px → 1440px+

## Tech & Standards
| Area | Details |
|------|---------|
| HTML5 | Semantic landmarks: `header`, `nav`, `aside`, `main`, `section`, `footer` |
| CSS3 | Mobile-first, CSS Grid (page layout), Flexbox (components), `clamp()` fluid type, container query |
| Breakpoints | Tablet `768px`, Desktop `1024px` |
| JavaScript | State management, DOM rendering, event delegation, localStorage |
| Palette | Mocha Mousse `#A5856F`, Ethereal Blue `#A0D4E0`, Moonlit Grey `#F2F0EA` |
| Fonts | Montserrat (headings), Roboto (body) – 2 families, 3 weights |
| Accessibility | WCAG AA contrast, skip link, visible focus, ARIA live region, 44px touch targets, keyboard support, reduced-motion |

Open `index.html` in a browser – no build step needed.
